Cutout transparency comparison

Same Blot cutout prompt and reference sheet across backends. Prompt-native asks for a real alpha PNG (no --cutout). Chroma + script uses flat #FF00FF and illo's --cutout post-process. Checkerboard + blue strip show whether backgrounds are actually transparent.

checkerblue (reveals white/green halos)

Findings

  • Codex CLI (gpt-image-2) · Prompt-native: clean alpha (transparent 776,976, fringe g/m 0/0)
  • Codex CLI (gpt-image-2) · Chroma + script: clean alpha (transparent 778,130, fringe g/m 0/0)
  • OpenRouter · grok-imagine · Prompt-native: no PNG alpha (JPEG or opaque PNG) (transparent 0, fringe g/m 0/0)
  • OpenRouter · grok-imagine · Chroma + script: failed — note: PyYAML not installed — reading only /Users/tmchow/.config/illo/config.yaml's flat keys (nested keys like watermark
  • OpenRouter · gemini-flash · Prompt-native: no PNG alpha (JPEG or opaque PNG) (transparent 0, fringe g/m 0/0)
  • OpenRouter · gemini-flash · Chroma + script: failed — note: PyYAML not installed — reading only /Users/tmchow/.config/illo/config.yaml's flat keys (nested keys like watermark
  • OpenRouter · gpt-image-2-or · Prompt-native: fully opaque — no transparency (transparent 0, fringe g/m 0/808)
  • OpenRouter · gpt-image-2-or · Chroma + script: clean alpha (transparent 733,365, fringe g/m 1/28)

Takeaways

  • Codex (gpt-image-2) delivered real alpha from the prompt alone — no chroma script required on this run.
  • OpenRouter Grok Imagine and Gemini Flash returned JPEG with no alpha; prompt-native failed; --cutout could not run (PNG-only post-process).
  • OpenRouter GPT Image 2 returned an opaque PNG for prompt-native (white corners); chroma + --cutout produced clean alpha.
  • When native alpha works, prefer prompt-native (simpler, no spill). Keep --cutout as fallback for models/backends that return opaque RGB/JPEG.
